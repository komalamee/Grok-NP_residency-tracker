# Leaving the UK: checklist of GOV.UK items (template)

Checked against live GOV.UK on **26 Sep 2026**. "GOV.UK updated" is the page's own last-updated date from the GOV.UK content API on that day. The bot re-opens each link before sending this checklist to a user and updates the dates; if a page has moved or changed, it says so rather than relying on this copy.

This is a list of official pages to look at and what each one says, so nothing is forgotten. It is not advice on what any one person should do, and whether an item applies depends on the person's circumstances. For decisions, take the records to a qualified adviser.

The bot keeps a copy in the user's data folder as `checklists/leaving-uk.md` with a status per item (to look at / done / not relevant, with the date), and files any documents that result (for example a P85 acknowledgement) in the documents index.

Record-keeping items Nomad Pro adds to the user's own log (not GOV.UK items): the departure date and first night abroad (midnight rule, RFIG20710), the last UK work day, when UK accommodation stopped being available (RFIG20550), and any status documents (tenancy end, sale completion, employment contract, P85 acknowledgement) filed in the documents index.
