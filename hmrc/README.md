# hmrc/ — HMRC Statutory Residence Test guidance mirror

A local copy of HMRC's Statutory Residence Test (SRT) guidance, so the bot can search it and cite each page with HMRC's own last-updated date. Contains public sector information licensed under the Open Government Licence v3.0; see [../HMRC-NOTICE.md](../HMRC-NOTICE.md).

| Path | What it is |
|---|---|
| `pages/` | One Markdown file per gov.uk page (143). HMRC's wording, converted from the GOV.UK content API; frontmatter carries `url`, `hmrc_updated`, `fetched`, `words`, `hash`. |
| `catalogue.md` | Every page, nested as in the manual, with word counts and links. Generated by `refresh.py`. |
| `manifest.json` | Machine-readable index: hash and HMRC update date per page. |
| `CHANGES.md` | Append-only log of changes found between refreshes. |
| `refresh.py` | Full re-crawl of the two roots (`python3 hmrc/refresh.py --check` reports only). |

Rules:

1. Nothing under `pages/` is written by hand or from memory; if a fetch fails, nothing is written.
2. A change here is a signal to read the page again, not an interpretation. Not tax advice.
3. Cite the page (e.g. "RFIG20560 (updated 3 Jul 2026)"), not this folder.

The engine's tools find this folder automatically (`<engine>/hmrc`). On a user's box, the bot works from the user's own copy in their data folder (`~/nomad-pro-data/hmrc`), which the weekly `tools/hmrc_watch.py` run keeps current; this copy stays as shipped so engine updates apply cleanly.
